# 续一集 · 重新设计（六候选）

> 共同 spec：安卓 App「续一集」（暂定名），给红果短剧（com.phoenix.read）做自动上滑。受众是躺着刷短剧的人，场景是夜里、单手、屏幕内容一直在动。核心信息：服务在跑 / 什么时候滑 / 广告怎么处理 / 出问题怎么看日志。输出：4 屏 Android 原型（主界面、剧集+悬浮球、悬浮球展开、运行日志），单文件可交互，展示板 1440×900。
> 悬浮球要同时回答三件事：现在是不是在跑、下一次什么时候滑、怎么立刻停。

## 1 · 最佳设计师｜田中一光（大胆）

- **逻辑与来源**：田中一光（Ikko Tanaka，1930–2002），日本战后平面设计代表人物，以能面、日本舞蹈海报里的几何化面容与极有限的平涂色块著称。这里不模仿他某张海报，而是用他的构成方法：圆形与方块的对位、色块切分版面、一种朱红只出现一次。参考样张：`assets/style-specimens/app/03-playful-3d.jpg` 只借「色块舞台」的胆量，不借 3D 材质。
- **借的是什么**：四色（墨黑 #17130F / 米白 #F2EBDD / 朱红 #C8321E / 灰绿 #6F7A63）；字号只分三档（96 / 22 / 13）；版面用色块切，不靠卡片和阴影；圆形只给悬浮球。
- **主角素材**：AI 生成的短剧剧照（`assets/drama.jpg`）＋ CSS 平涂色块蒙版；悬浮球是朱红实心圆，像戏台上的一束追光。
- **骨架**：主界面是一张「戏单」——左边 60% 放巨大竖排「续」字与状态，右边 2×3 色块网格放设置；剧集屏只有一颗红圆压在画面右下；展开面板是从底部升起的一块米白节目单。
- **胆量花在哪**：把系统设置做成一张海报，巨大的「续」字切掉半屏，所有控件退到另一半。
- **form 来自内容的哪里**：短剧是连台本戏，一集接一集；界面该像戏单/海报，而不是系统设置页。

## 2 · 最佳设计师｜Jasper Morrison（克制）

- **逻辑与来源**：Jasper Morrison（1959– ），英国产品设计师，「super normal」的提出者：好东西应该安静到不被注意，只在做工上讲究。把他对实物的分寸感搬到屏幕上——没有装饰、没有渐变、只有一个哑光物件。
- **借的是什么**：单列 64px 行高、1px 发丝线、统一的 10px 圆角；层级只用间距和字重；控件按下只降 2% 明度；悬浮球像一颗磨砂鹅卵石，只有一道刻线表示进度。
- **主角素材**：同一张剧照，降饱和 + 轻微暗角；悬浮球的哑光材质用多层内外阴影做（不是玻璃，是磨砂塑料）。
- **骨架**：设置页一张白纸，单列到底，底部一枚灰色小胶囊；剧集屏的球 44px、静置 55% 不透明度，点一下才升到 100%；展开是球旁边浮出的一列 5 个圆形小按钮。
- **胆量花在哪**：敢让悬浮球几乎消失——不运行的时候只留 12% 的一条弧，像一个呼吸点。
- **form 来自内容的哪里**：这是遥控器式的工具，应该退到手里，不抢剧；「不用动手」的前提是「不用看它」。

## 3 · 现实参照｜Halide Mark II（专业相机）

- **逻辑与来源**：Halide Mark II（Lux Optics，Apple Design Award），真实界面已看，参考板 `refs/board-apps-1.jpg`。借它「取景器 + 底部参数架」的组织方式：内容占满，控件是一条随时可收的横条；单一黄色只给当前焦点；刻度尺两端渐隐。
- **借的是什么**：纯黑 #000 底 + 亮黄 #FFCC00 + 灰白读数；等宽数字；底部一条参数行（模式 / 间隔 / 广告策略）+ 横向刻度 + 圆形主钮；参数行可以下滑收起；黄色全屏不超过三处。
- **主角素材**：剧照铺满 + 半透明 HUD；悬浮球是一枚黄色对焦环，环内的数字是「距离下一次上滑」的秒数。
- **骨架**：剧集屏上半 62% 是画面，下半是一条固定的控制架；主界面沿用同一套刻度语言，把「间隔 25 秒」做成一条可拖的尺；日志页是等宽滚动的黑底绿字。
- **胆量花在哪**：把自动上滑做成一台相机——你能看见「下一次动作」什么时候发生，像看快门。
- **form 来自内容的哪里**：自动上滑的本质是「等一个时机，然后按一下」，和按快门是同一种动作。

## 4 · 现实参照｜Streaks（习惯追踪）

- **逻辑与来源**：Streaks（Crunchy Bagel，Apple Design Award），真实界面已看，参考板 `refs/board-apps-2.jpg`。借它「白色圆环按钮 + 环内数字 + 环外标签」的图标系统，以及整屏一个饱和渐变、只留一个白色浮钮的做法。
- **借的是什么**：珊瑚橙 #FF6B4A → 紫 #7B5CE6 的整屏渐变；2 列圆环网格；环的缺口表示进度；状态用颜色编码（运行=薄荷 #7FE3C0、暂停=珊瑚、广告等待=琥珀）；白色只给「现在要做的那一个」。
- **主角素材**：剧照做顶部 1/3 窄条；主体是四个大圆环（智能 / 定时 / 广告 / 日志）；悬浮球就是第五个环，环里是倒计时秒数。
- **骨架**：主界面 2×2 圆环铺满，底部一行状态字；剧集屏球 56px，环上的缺口随时间闭合；展开面板是 2×2 的小环。
- **胆量花在哪**：整屏渐变 + 五个同构的环，把「等待」这件无聊的事变成看得见的进度。
- **form 来自内容的哪里**：连看短剧是一种「连击」，环让每一集的等待都有反馈。

## 5 · 秒数轮盘｜App #3 玩味3D材质 Playful Tactile（大胆·还原 70%）

- **逻辑与来源**：秒数 S=50 → App 分区第 3 号：(Not Boring) 系列（Andy Works，(Not Boring) Habits 获 2022 Apple Design Award）。样张 `assets/style-specimens/app/03-playful-3d.jpg` 已看：满版饱和色、厚底边硬阴影、凸起表盘、一屏一个主角。
- **借的是什么**：每屏一个满版主色（薰衣草 #B6A2FF / 橙 #FF7A2D / 酸绿 #D4FF3F）；近黑 #1B1330 文字；按钮有多层 box-shadow（实色下沿 + 内高光 + 外软阴影），按下去会位移 3px；数字大而圆、紧字距。
- **主角素材**：程序化 3D 悬浮球（radial-gradient 球面高光 + 硬下沿）＋ 剧照做小窗；主界面的主角是一个巨大的实体开始钮。
- **骨架**：主界面一颗 220px 的凸起圆钮（中间是状态），下面三块厚卡片；剧集屏球 64px，展开成一张厚面板（间隔用一排凸起圆键 15/25/40/60）。
- **胆量花在哪**：悬浮球本身是最有存在感的物件，像一颗真的按键，值得被捏一下。
- **form 来自内容的哪里**：刷短剧要的就是「爽感」，控件为什么不能有手感。
- **诚实标注**：触感反馈和按压缩放动画静态图验证不了；HTML 里只写 transition，还原度约 70%。

## 6 · 秒数轮盘｜东亚 #3 民国书衣 Republic-Era Book Jacket（中性·还原 70%）

- **逻辑与来源**：秒数 S=50 → 东亚分区第 3 号：鲁迅与陶元庆一代的书刊封面（陶元庆为鲁迅设计《彷徨》《坟》《朝花夕拾》）。样张 `east/03-republic-book-jacket.jpg` 已看：纸色底、白色题签、竖排书名、细双线框、平涂几何山与日、一点朱红。
- **借的是什么**：土黄纸色 #DED3B8 + 墨黑 #1E1A15 + 朱红 #B03A2E 三色；白色题签条 + 细双线框；竖排标题；图案只用平涂多边形（山、日、横水纹）；小字像版权页。
- **主角素材**：剧照去色偏暖做「旧照」；悬浮球是一方朱印「续」，印在画面右下角；展开面板是一张从右侧抽出的题签。
- **骨架**：主界面是一张书衣——右起竖排「续一集」，左侧题签条里放开关，底部版权页式小字放权限与版本；剧集屏只有一枚 40px 的印章。
- **胆量花在哪**：把工具做成一本 1930 年代的话本封面，设置项像版权页。
- **form 来自内容的哪里**：短剧就是当代的章回话本，一集一回，「续」字本身就是产品。
- **诚实标注**：手写题签、纸张纤维、做旧与套色错位纯 CSS 做不到，降级为平涂纸色 + 楷体，还原度约 70%。
